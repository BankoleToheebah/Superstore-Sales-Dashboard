# Superstore-Sales-Dashboard
- A retail sales analysis dashboard built with Power BI to explore sales, profit, customer segments, regional performance, and yearly sales trends.
# Project Overview
- This project uses Power BI to analyze retail sales data and identify trends in sales, profit, and customer segments.
# Objectives
- Analyze total sales and total profit.
- Compare sales across categories, regions, and customer segments.
- Track yearly sales trends.
- Identify profitable and less profitable product sub-categories.
# Tools Used
- Microsoft Power BI
- Microsoft Excel
# Dashboard Features
- Total Sales, Total Profit, and Total Orders summary cards.
- Sales by Category and Sub-Category.
- Yearly Sales Trend.
- Region and Year Slicers for interactive filtering.
# Key Learning Outcomes
- This project helped develop skills in data visualization, dashboard design, and exploratory sales analysis.
